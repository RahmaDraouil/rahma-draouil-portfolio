═══════════════════════════════════════════════════════════════════
  ⚠️ ERREURS FRÉQUENTES
═══════════════════════════════════════════════════════════════════

❌ Nom de fichier incorrect
   ✅ Solution : Respectez EXACTEMENT les noms :
      • photo-rahma.png (tout en minuscules)
      • CV_Rahma_Draouil.pdf (avec majuscules et underscores)

❌ Mauvais dossier
   ✅ Solution : Placez les fichiers aux bons endroits :
      • Photo : public\images\
      • CV    : public\documents\

❌ La photo ne s'affiche pas après ajout
   ✅ Solution : 
      1. Arrêtez le serveur (Ctrl+C)
      2. Relancez : npm run dev
      3. Rechargez la page (Ctrl+F5)
